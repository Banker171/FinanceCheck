# Развитие финансового аналитика

## Что уже есть

Детерминированный расчетный модуль, проверенные сценарии и интерфейс внешней модели с минимизацией передаваемых данных. Личный финансовый контекст передается во время запроса: для этого не требуется обучение модели. Локальный режим доступен без ключа.

## Почему нельзя «обучить по максимуму» на операциях

Транзакции, остатки и ставки — входные данные, а не эталонные ответы. Автоматически обучая модель на собственных ответах без проверки, можно закрепить ошибки и воспроизвести персональную информацию. Длительность обучения и размер модели не доказывают качество финансовых советов.

## Практический следующий этап

1. Составить обезличенный набор ситуаций: устойчивый доход, нерегулярный доход, дефицит, дорогие займы, нулевые ставки, просрочки, кредитные каникулы, неполные данные и иждивенцы. Синтетические ситуации помечать как синтетические.
2. Для каждого примера сохранить исходные данные, эталонный расчет, допустимые выводы и вопросы, которые помощник обязан уточнить. Ответы проверяет финансовый специалист. Не считать любой выбор пользователя правильным обучающим ответом.
3. Разделить обучение и оценку по пользователям/ситуациям, чтобы почти одинаковые истории не попали в обе выборки. Получить отдельное явное согласие, определить сроки хранения, удаление и назначение данных. Не отправлять реальные истории в обучение по умолчанию.
4. Сначала измерить базовую модель с расчетными инструментами: точность сумм и сроков, долю выдуманных фактов, обнаружение дефицита, соблюдение согласия, качество уточняющих вопросов и ясность объяснений. Нынешние тесты API проверяют подключение и состав сводки, а не эти свойства реального ответа.
5. Если сохраняются устойчивые недостатки формата или диалога, дообучить готовую модель на проверенных примерах. Текущие остатки и личную историю продолжать получать из приложения при запросе; не вшивать их в веса модели.
6. Сравнить модель с исходной на отложенной выборке, включая финансовые ошибки и попытки изменить инструкции. Выпускать новую версию только после проверки, сохраняя возможность отката.

Для реального запуска обучения еще нужны подготовленная выборка, выбранный провайдер/доступное оборудование, ключи, бюджет и критерии приемки. Ни обученная собственная модель, ни подтвержденное качество внешнего финансового консультанта в текущей версии не заявляются.
